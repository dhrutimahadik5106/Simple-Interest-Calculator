
# Contributing Guidelines

Thank you for your interest in contributing to the
Simple Interest Calculator project!

## Contributions Welcome

All contributions, bug reports, bug fixes, documentation
improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Clone the repository to your local machine.
3. Create a new branch for your changes.
4. Make your improvements or bug fixes.
5. Commit your changes.
6. Push your branch to GitHub.
7. Submit a Pull Request.

## Reporting Bugs

If you find any bugs, please create an issue describing
the problem and the steps to reproduce it.

## Suggestions and Enhancements

Suggestions for new features and improvements are
always welcome.

## Documentation

Contributions that improve project documentation,
examples, and instructions are appreciated.

## Code of Conduct

Please follow the guidelines mentioned in the
CODE_OF_CONDUCT.md file.

Thank you for contributing!
