
# Simple Interest Calculator

## Description
This project is a Simple Interest Calculator that calculates
the interest earned or payable on a principal amount over
a specified period at a given annual interest rate.

## Formula
Simple Interest = (P * R * T) / 100

Where:
- P = Principal Amount
- R = Annual Rate of Interest (%)
- T = Time Period (Years)

## Features
- Calculates simple interest.
- Accepts principal, rate, and time as inputs.
- Displays the calculated interest.
- Easy to understand and use.

## Example
Principal Amount: 10000
Rate of Interest: 5%
Time Period: 2 years

Simple Interest = (10000 * 5 * 2) / 100
Simple Interest = 1000

Total Amount = 11000
